# 25/50 セッション帳

パーソナルトレーニングの現場用メニュー帳。`index.html` 1ファイルで完結します（ビルド不要、ブラウザで開くだけ）。

## 前提としているセッション

筋トレ → キックボクシングの順で進行します。

| プラン | 準備運動 | 筋トレ | キック | 整理運動 |
|---|---|---|---|---|
| 25分 | 2分 | 12分（4種目 × 3周） | 10分 | 1分 |
| 50分 | 3分 | 30分（4種目 × 3周 × 2ブロック） | 15分 | 2分 |

- 客層はトレーニング初心者が中心
- 担当トレーナーが毎回変わるため、重量を次回に伸ばす設計はせず、**1回の満足度を最大化する構成**
- 全種目サーキット。**周ごとに重量を1段ずつ上げ、回数は種目ごとに固定**
- 設備は バーベル20kg・EZバー・ラットプルダウン・可変式ダンベル・トレーニングバンド・ステップ台・マット

## 切り替えの軸

`25分 / 50分` × `下半身 / 上半身 / 全身` × `女性 / 男性` × `20代 / 30代 / 40代 / 50代` の48通り。ページ上部の4つのトグルで切り替えます。

- **下半身は男女で種目が違います。** 男性版はヒップ系（ヒップスラスト・クラムシェル・ヒップリフト）を外しています
- **全身は1種目目をプレス種目**（男性はベンチプレス、女性はダンベルプレス）にしています。大きい筋肉から入る原則は保ちつつ、最初に手応えが立つ順序にするためです

## 重量の決まり方

**40代を基準**に、年齢層で係数をかけて引き直します。

| 年齢 | 係数 |
|---|---|
| 20代 | +25% |
| 30代 | +15% |
| 40代 | 基準 |
| 50代 | −15% |

そのままでは現場で作れない重量（3.5kg など）になるため、実在する刻みにスナップさせています。

- ダンベル … `1 / 1.5 / 2 / 2.5 / 3 / 4 / 5 / 6 / 7 / 8 / 9 / 10 / 12 / 14 / 16 / 18 / 20 / 22 / 24 kg`
- バーベル … 20kg 始まりの5kg刻み（2.5kgプレート × 2）
- ラットプルダウン … 5kg刻み
- EZバーの追加プレート … 2.5kg刻み

丸めた結果 3段階が同じ重量に潰れることがあるため、**単調増加を保証する処理**を入れてあります（前の周と同じか軽くなった場合は次の刻みへ繰り上げ）。

## 進行表

タイムラインの上に、全種目の重量・回数・所要時間の一覧を置いています。

- チェックすると **残り種目数と残り時間** が更新される
- 行をタップすると該当種目の詳細へスクロール
- 25分は4種目すべてが iPhone 1画面に収まる

## 編集のしかた

`index.html` 末尾の `<script>` 内を編集します。

| 定数 | 内容 |
|---|---|
| `FIG` | 棒人間の動作図（SVG） |
| `EX` | 種目マスタ。種目名・対象部位・回数・手順・声かけ・よくあるミス・重量の刻み（`u`） |
| `P` | 12パターンのブロック構成。重量は40代基準で書く |
| `AGE` | 年齢層の係数と、年齢ごとの注意書き |
| `REF` | 重量早見表のもとデータ（40代基準） |
| `WARM` / `INTAKE` / `ASK` / `COOL` | 来店・準備運動・整理運動 |

種目を追加するときは `FIG` に棒人間SVGを足し、`EX` に定義を追加（`u` に `bar` / `stack` / `plate` / `db` / `none` のいずれかを指定）してから `P` で参照します。
