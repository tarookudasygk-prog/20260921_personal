# 25/50 セッション帳

パーソナルトレーニングの現場用メニュー帳。`index.html` 1ファイルで完結します（ビルド不要、ブラウザで開くだけ）。

## 前提としているセッション

筋トレ → キックボクシングの順で進行します。

| プラン | 着替え・体操 | 筋トレ | キックボクシング |
|---|---|---|---|
| 25分 | 3分 | 12分（5種目 × 2周） | 10分 |
| 50分 | 4分 | 30分（4種目 × 3周 × 2ブロック） | 15分 |

- 客層は40〜50代・トレーニング初心者が中心
- 担当トレーナーが毎回変わるため、重量を次回に伸ばす設計はせず、**1回の満足度を最大化する構成**
- 設備は バーベル20kg・ラットプルダウン・可変式ダンベル・トレーニングバンド・ステップ台・マット

## 収録パターン

`25分 / 50分` × `下半身 / 上半身 / 全身` × `女性 / 男性` の12パターン。ページ上部の3つのトグルで切り替えます。

各種目に以下を掲載しています。

- 棒人間の動作図（SVG）
- 重量・回数・1セットの目安時間
- セットアップ手順（3ステップ）
- そのまま言える声かけ例
- よくあるミスと、その場で直す一言

## ファイル

| ファイル | 内容 |
|---|---|
| `index.html` | メニュー帳本体。種目マスタ・プラン定義・棒人間SVGをすべて内包 |
| `.claude/launch.json` | ローカルプレビュー用の設定（`python3 -m http.server 8765`） |

## 編集のしかた

`index.html` 末尾の `<script>` 内、2つのオブジェクトを編集します。

- `EX` — 種目マスタ。種目名・対象部位・動作図・手順・声かけ・よくあるミス
- `P` — プラン定義。12パターンそれぞれのブロック構成、重量、回数、時間配分

種目を追加するときは `FIG` に棒人間SVGを足し、`EX` から参照してください。
